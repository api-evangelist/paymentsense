# Paymentsense

> Paymentsense (now part of Dojo) is a United Kingdom payment processor offering card acceptance to SMBs through card terminals (PDQ), online gateways, and EPOS integrations. Its developer surface is the Connect platform: a cloud integration layer giving each merchant an isolated host so point-of-sale and hospitality software can drive card terminals without touching card data. Authentication is HTTP Basic (Connect) or a JWT/access-token pair (Connect-E). Versioning is by `Accept` media type (application/connect.v0+json .. v2+json).

## APIs

- [Connect REST API](https://docs.connect.paymentsense.cloud/rest/api): Cloud REST API to drive card terminals from EPOS software — Pay-At-Counter (/pac) and Pay-At-Table (/pat). Published as v0 (Swagger 2.0), v1 (Swagger 2.0), v2 (OpenAPI 3.0, current).
- [Connect-E REST API](https://docs.connect.paymentsense.cloud/ConnectE/RestApi): OpenAPI 3.0 REST API for online / e-commerce card payments — access tokens, payments, cross-reference (repeat) payments, payment methods. Proxies CyberSource.
- [Connect WebSockets API](https://docs.connect.paymentsense.cloud/websockets/api): Event-driven JSON-RPC2 alternative to REST for terminal integration (pac/pat).
